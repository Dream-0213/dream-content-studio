## 项目介绍

这是 Dream 内容推广工作室的官方网站项目。

工作室面向人工智能、大模型、开发工具、云计算、数据库、企业软件及国产软硬件生态，提供技术内容策划与原创、CSDN KOL 投放、公众号博主矩阵、多平台内容分发、大型征文招募和长期内容运营服务。

目前合作网络覆盖：

- 300+ 位万粉技术博主
- 700+ 位内容分发博主
- 100+ 位公众号合作博主
- CSDN、微信公众号、知乎、掘金、华为云、腾讯云、51CTO 等内容平台

## 网站内容

- 工作室及主理人 Dream 介绍
- 技术内容营销服务说明
- 飞算 JavaAI、华为昇腾及鲲鹏、ToDesk、程聚宝、星空组网、360 AI 等合作案例
- CSDN 与公众号合作博主矩阵
- 博主名单搜索、筛选与 Excel 导出
- 商务合作与创作者加入入口

## 本地运行
